# 双休聘 隐私政策

**版本：1.0　生效日期：2026-09-13**

「双休聘」（以下简称"我们"）深知个人信息对您的重要性。本政策说明我们如何收集、使用、存储和保护您的个人信息，以及您享有的相关权利。**请在使用前仔细阅读；使用本平台即表示同意本政策。**

## 1. 我们收集的信息

1.1 **账号信息**：注册邮箱、密码（仅保存单向加密后的散列值，我们无法获知明文）、您主动设置的昵称、头像、简介与联系邮箱。

1.2 **内容信息**：您发布的帖子、评论、企业评价、职位信息，以及由此产生的互动数据（点赞、关注、转发、评分）。

1.3 **核验信息**：注册、找回密码时用于身份核验的邮箱验证码记录（含发送与校验状态）。

1.4 **技术信息**：为保障服务安全稳定所必需的最小化日志（访问时间、IP 地址、请求路径）。

## 2. 信息的使用

2.1 提供核心功能：职位检索、社区互动、企业点评、消息通知、在线状态维持。

2.2 保障安全：身份核验、频率限制（验证码 60 秒一次、每日上限）、违规内容治理、会话保持与账号保护。

2.3 人工审核：您提交的企业认证申请（含企业名称、联系邮箱、说明）将由运营人员人工审核，审核所需信息不会用于其他目的。

2.4 **我们不会将您的个人信息出售给任何第三方。**

## 3. 信息的存储与保护

3.1 密码经 bcrypt 单向加密存储；登录会话数据保存于服务端缓存并设置有效期，Cookie 仅携带随机会话标识且开启 HttpOnly。

3.2 业务数据存储于具备访问控制的数据库中，仅授权人员可在履行职责所必需的范围内访问（例如认证审核）。

## 4. 信息的公开与共享

4.1 您主动公开的内容（帖子、评价、昵称、头像、联系邮箱）将对其他用户可见，请谨慎填写。

4.2 除法律法规要求或取得您的明确同意外，我们不会向第三方提供您的个人信息。

## 5. 您的权利

5.1 您可随时在"我的 → 编辑资料"中查看、更正个人资料，删除自己发布的帖子与评论。

5.2 如需注销账号或行使其他法定权利，可通过平台公布的联系方式与我们联系，我们将在 15 个工作日内响应。

## 6. 未成年人保护

本平台面向求职者与职场用户。未成年人应在监护人同意并指导下使用本平台。

## 7. 政策更新

本政策可能适时更新，更新后将在平台内公示；重大变更将以显著方式提示。
